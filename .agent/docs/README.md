# Agent Documentation Index

This folder contains AI-facing documentation used by workflow rules and documentation guardrails.

## Core Governance

- `structure.md` — file-area -> required-doc ownership map.
- [`doc-map.json`](./doc-map.json) — machine-readable mapping used by `docs:sync` and `docs:check`.
- `architecture.md` — architecture, data flow, and build/release documentation requirements.

## Operational References

- `release-workflows.md` — approved push/release flows and branch promotion rules.
- `project-reference.md` — runtime constraints, conventions, key files, and commands.
- `known-issues-disabled-features.md` — disabled features and operational troubleshooting notes.

## Contributor-facing docs

- Root `README.md` and `.github/CONTRIBUTING.md` are the human-facing entry points.
- `docs/README.md` indexes the general project documentation folder.
