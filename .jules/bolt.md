## 2025-03-05 - Avoid multiple array allocations in React render cycle by combining `.filter` calls
**Learning:** In heavily used `useMemo` hooks (like filtering a large library of games for display), chaining multiple `.filter()` calls creates an intermediate array in memory for each call. This adds GC pressure and increases iteration overhead. Additionally, calling `[...filtered].sort(...)` right after filtering allocates yet another array when `filtered` is already a freshly allocated array that is safe to mutate with an in-place sort.
**Action:** When filtering data sets in a React render cycle (or a `useMemo`), combine multiple conditions into a single `.filter()` pass. If a sort is needed immediately afterward, apply it in-place using `.sort()` on the newly filtered array rather than creating a shallow copy first.
