## 2024-05-24 - [List Rendering Performance with CSS Content Visibility]
**Learning:** Virtualization libraries like `react-window` can add significant complexity to components rendering dynamic row heights and variable structures. Using the CSS property `contentVisibility: 'auto'` on list items, paired with dynamically calculated `containIntrinsicSize`, offers a lightweight, native browser alternative. This defers rendering of off-screen list items, dramatically improving initialization and scroll performance for large collections (like games libraries) without external dependencies.
**Action:** When faced with performance bottlenecks in long scrolling lists, apply `contentVisibility: 'auto'` and `containIntrinsicSize` to the main list item wrappers before reaching for full virtualization solutions, provided the list items have predictable or calculable dimensions.
