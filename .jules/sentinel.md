## 2025-02-12 - Cross-Site Scripting (XSS) Vulnerability in Game Descriptions
**Vulnerability:** Game descriptions fetched from external sources (such as IGDB, GiantBomb, Steam, etc.) or edited by the user were being rendered directly using `dangerouslySetInnerHTML` in `LibraryCarousel.tsx` and `GameDetailsPanel.tsx` without prior HTML sanitization. This allowed for the execution of arbitrary JavaScript via malicious `<script>` tags embedded in the description content.
**Learning:** External metadata fetches or imported custom HTML cannot be trusted blindly. Whenever an application renders HTML content retrieved from a third party or generated by a user via `dangerouslySetInnerHTML`, it exposes an XSS surface. The app's architecture previously had a gap where metadata content was stored and rendered as-is.
**Prevention:** All external or user-provided HTML must be sanitized using a trusted library (like `dompurify`) before rendering it to the DOM.
